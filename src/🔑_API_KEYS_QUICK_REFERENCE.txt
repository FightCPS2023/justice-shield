🚨 COMMON MISTAKES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Wrong file location (.env in /components/)
   ✅ Put .env in ROOT folder

❌ Forgot VITE_ prefix
   ✅ Must start with VITE_ for client-side

❌ Spaces around equals sign (KEY = value)
   ✅ No spaces (KEY=value)

❌ Forgot to restart server
   ✅ Always restart after editing .env
