STEP 1: Enable Email Auth (1 minute)
─────────────────────────────────────────────────────────────────────────────
1. Go to: https://supabase.com/dashboard/project/rdrpwrwjqayhbsyxqaej
2. Click: Authentication → Providers (left sidebar)
3. Find: "Email" provider
4. Enable it
5. TURN OFF "Confirm email" (important!)
6. Save

STEP 2: Get Your Anon Key (1 minute)
─────────────────────────────────────────────────────────────────────────────
1. Same dashboard → Settings → API
2. Under "Project API keys"
3. Copy the "anon public" key
   (looks like: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...)

STEP 3: Update Your Code (1 minute)
─────────────────────────────────────────────────────────────────────────────
Open: /utils/supabase/info.tsx
