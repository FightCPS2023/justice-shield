================================================================================
TROUBLESHOOTING:
================================================================================

"Failed to fetch" or "Network error"
→ Check .env file has correct Supabase URL and anon key
→ Verify internet connection
→ Check Supabase project is not paused at app.supabase.com

"Invalid API key" or "Authentication failed"
→ Double-check VITE_SUPABASE_ANON_KEY in .env
→ Make sure key starts with: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9
→ No spaces before/after the = sign
→ Restart dev server: npm run dev

"Gemini API error"
→ Check VITE_GEMINI_API_KEY is correct
→ Verify key at: https://aistudio.google.com/app/apikey
→ Gemini needs billing enabled (free tier is fine)

Blank white screen
→ Press F12 to open browser console
→ Look for red error messages
→ Check if .env file exists in project root
→ Clear browser cache: Ctrl+Shift+Del

"relation does not exist" error
→ Database tables didn't create properly
→ Go back to Supabase SQL Editor
→ Re-run the SQL from /📊_SUPABASE_DATABASE_SETUP.sql

Can't create account
→ Check browser console (F12) for specific error
→ Verify Supabase anon key is correct
→ Check Supabase project is active

Case won't save
→ Database connection issue
→ Verify database tables were created
→ Check browser console for error details
→ Check Supabase logs at app.supabase.com

================================================================================
BROWSER CONSOLE TIPS:
================================================================================

How to open console:
- Chrome/Edge: Press F12
- Mac: Cmd+Option+I
- Right-click → "Inspect" → "Console" tab

Look for:
❌ Red errors = Something is broken
⚠️ Yellow warnings = Usually OK, might affect some features
✅ No errors = Everything is working!

Common errors and fixes:
- "CORS error" = Supabase configuration issue
- "401 Unauthorized" = Wrong API key
- "404 Not Found" = Missing route or file
- "Failed to fetch" = Network/API issue
