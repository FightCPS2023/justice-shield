================================================================================
                            TROUBLESHOOTING TREE
================================================================================

Problem: "Environment variables not loaded"
  │
  ├─→ Check: .env file in project root? → No → Create .env file
  │                                     → Yes → Continue
  ├─→ Check: File named exactly ".env"? → No → Rename to .env
  │                                      → Yes → Continue
  ├─→ Check: Variables start with VITE_? → No → Add VITE_ prefix
  │                                       → Yes → Continue
  └─→ Solution: Restart dev server (npm run dev)

Problem: "Cannot connect to Supabase"
  │
  ├─→ Check: Internet connection? → No → Fix connection
  │                                → Yes → Continue
  ├─→ Check: Project active? → No → Go to app.supabase.com and restore
  │                           → Yes → Continue
  ├─→ Check: URL correct? → No → Verify in Supabase dashboard
  │                        → Yes → Continue
  └─→ Solution: Check credentials in .env match Supabase

Problem: "Gemini API error"
  │
  ├─→ Check: API key set in .env? → No → Add to .env
  │                                → Yes → Continue
  ├─→ Check: Restarted server? → No → Restart: npm run dev
  │                             → Yes → Continue
  ├─→ Check: API key valid? → No → Get new key at aistudio.google.com
  │                          → Yes → Continue
  └─→ Solution: Check you haven't exceeded free tier

Problem: "RLS policy violation"
  │
  ├─→ Check: Logged in? → No → Log in or create account
  │                      → Yes → Continue
  ├─→ Check: SQL script run? → No → Run SQL in Supabase
  │                           → Yes → Continue
  ├─→ Check: Tables exist? → No → Run SQL script again
  │                         → Yes → Continue
  └─→ Solution: Log out and back in

Problem: "Cannot upload documents"
  │
  ├─→ Check: Storage bucket exists? → No → Create "documents" bucket
  │                                  → Yes → Continue
  ├─→ Check: Policies created? → No → Add storage policies
  │                             → Yes → Continue
  ├─→ Check: Logged in? → No → Log in
  │                      → Yes → Continue
  └─→ Solution: Check browser console for specific error
