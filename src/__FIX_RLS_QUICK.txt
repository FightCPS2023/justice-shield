═══════════════════════════════════════════════════════════════

ISSUE:
───────────────────────────────────────────────────────────────
Table: public.evidence
Policy: "Users can update own evidence"
Problem: Calls auth.uid() for EVERY ROW (slow!)


THE FIX:
───────────────────────────────────────────────────────────────
Wrap auth.uid() in a subquery → 10x-100x faster!

Change from:  auth.uid() = user_id
Change to:    (select auth.uid()) = user_id


═══════════════════════════════════════════════════════════════
QUICK FIX (30 SECONDS)
═══════════════════════════════════════════════════════════════

1. Open Supabase Dashboard: https://supabase.com/dashboard
2. Your project → SQL Editor → New query
3. Copy-paste this:

-- Drop old policy
DROP POLICY IF EXISTS "Users can update own evidence" 
ON public.evidence;

-- Create optimized policy
CREATE POLICY "Users can update own evidence"
ON public.evidence
FOR UPDATE
TO authenticated
USING ((select auth.uid()) = user_id)
WITH CHECK ((select auth.uid()) = user_id);

4. Click "Run" (Ctrl+Enter)
5. ✅ Done! 10x faster!
