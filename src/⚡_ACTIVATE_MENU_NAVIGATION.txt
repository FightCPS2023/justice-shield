═══════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "Can't activate new version"
Solution:
  1. Make sure you're in the project root folder
  2. Check that App_New.tsx exists
  3. Use Option 2 (manual copy-paste) instead

Problem: "Getting errors after activation"
Solution:
  1. Clear browser cache
  2. Clear localStorage: localStorage.clear() in console
  3. Refresh page (Ctrl+F5)
  4. Restart dev server

Problem: "Main menu not showing"
Solution:
  1. Check console for errors
  2. Verify /components/MainMenu.tsx exists
  3. Verify /pages/*.tsx files exist
  4. Clear browser cache

Problem: "Back button not working"
Solution:
  1. Should work automatically
  2. If not, refresh page
  3. Check console for errors
