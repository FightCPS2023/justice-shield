   CREATE POLICY "Users can upload own documents"
   ON storage.objects FOR INSERT
   WITH CHECK (
     bucket_id = 'documents' AND
     auth.uid()::text = (storage.foldername(name))[1]
   );

   CREATE POLICY "Users can view own documents"
   ON storage.objects FOR SELECT
   USING (
     bucket_id = 'documents' AND
     auth.uid()::text = (storage.foldername(name))[1]
   );

   CREATE POLICY "Users can delete own documents"
   ON storage.objects FOR DELETE
   USING (
     bucket_id = 'documents' AND

🐛 QUICK TROUBLESHOOTING
================================================================================

❌ "Cannot connect to Supabase"
   → Check internet connection
   → Verify project at: https://app.supabase.com
   → Restart dev server: npm run dev

❌ "Gemini API error"
   → Add API key to /.env (Step 1)
   → Restart dev server
   → Verify at: https://aistudio.google.com

❌ "RLS policy violation"
   → Make sure you're logged in
   → Verify database SQL ran successfully (Step 2B)
   → Try logging out and back in

❌ "Cannot upload documents"
   → Verify storage bucket exists (Step 2C)
   → Verify policies were created
   → Make sure you're logged in

❌ "Environment variables not loaded"
   → Verify .env is in project root
   → File named exactly: .env (not .env.txt)
   → Restart server: npm run dev
   → Variables must start with VITE_
