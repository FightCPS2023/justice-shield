DEPLOYMENT OPTION 1: VERCEL (RECOMMENDED - 10 MINUTES)
================================================================================

WHY VERCEL?
✅ Free tier available
✅ Automatic HTTPS/SSL
✅ Global CDN
✅ Easy environment variables
✅ One-command deployment
✅ Perfect for React/Vite apps

STEPS:

1. BUILD YOUR APP:
   npm run build

2. INSTALL VERCEL CLI (if not already):
   npm install -g vercel

3. LOGIN TO VERCEL:
   npx vercel login

4. DEPLOY:
   npx vercel --prod

5. FOLLOW PROMPTS:
   - Setup new project? Yes
   - What's your project name? cps-punisher (or your choice)
   - Which directory? ./ (press Enter)
   - Want to override settings? No (press Enter)

6. ADD ENVIRONMENT VARIABLES:
   After deployment, go to:
   https://vercel.com → Your project → Settings → Environment Variables
   
   Add these variables:
   VITE_SUPABASE_URL=https://rdrpwrwjqayhbsyxqaej.supabase.co
   VITE_SUPABASE_ANON_KEY=your_anon_key
   VITE_GEMINI_API_KEY=your_gemini_key
   VITE_COURTLISTENER_API_KEY=af0d9091a42930e5b9f90dd3bf9efad5c621357d

7. REDEPLOY:
   npx vercel --prod

✅ YOUR APP IS LIVE!

Your URL will be something like:
https://cps-punisher.vercel.app
or
https://your-project-name.vercel.app

DEPLOYMENT OPTION 3: YOUR OWN SERVER
================================================================================

REQUIREMENTS:
- Web server (Apache, Nginx, etc.)
- Node.js installed
- Domain name (optional)

STEPS:

1. BUILD:
   npm run build

2. UPLOAD:
   Upload entire /dist folder to your server's public directory
   Example: /var/www/html or /public_html

3. CONFIGURE SERVER:
   - Point domain to /dist folder
   - Enable HTTPS (use Let's Encrypt)
   - Configure SPA routing (redirect all to index.html)

4. ENVIRONMENT VARIABLES:
   Create .env file on server with your variables

✅ YOUR APP IS LIVE!
